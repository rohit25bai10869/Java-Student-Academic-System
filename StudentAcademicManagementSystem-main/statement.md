# Project Statement

## 1. Problem Statement

Managing student academic information manually can make it difficult to maintain student details, course marks, attendance records, and academic performance in an organized manner.

The **Student Academic Management System** is a command-line Java application developed to provide a simple and structured way to manage these academic records.

The system allows users to add, display, search, update, and delete student information. It also supports course marks and attendance management, academic performance calculation, report generation, and file-based student record storage.

---

## 2. Project Scope

The scope of the project includes:

- Managing student information.
- Adding and managing course marks.
- Calculating total and average marks.
- Calculating overall grades.
- Managing attendance information.
- Calculating attendance percentage.
- Generating academic performance reports.
- Saving student records to text files.
- Reading previously saved student records.
- Validating user input.
- Demonstrating Java and Object-Oriented Programming concepts.

The current system is implemented as a command-line application. Database storage and graphical user interface functionality are outside the current scope.

---

## 3. Target Users

The intended users of the system are:

- Students who need to manage basic academic information.
- Teachers or instructors who require a simple academic record management system.
- Beginners learning Java and Object-Oriented Programming.
- Academic evaluators reviewing practical Java implementations.

---

## 4. High-Level Features

### Student Management

- Add student
- Display all students
- Search student using Student ID
- Update student information
- Delete student

### Academic Management

- Add course marks
- Calculate total marks
- Calculate average marks
- Determine overall grade

### Attendance Management

- Store total classes
- Store attended classes
- Calculate attendance percentage
- Display attendance status

### Report Management

- Generate academic performance reports
- Display student academic information
- Display course performance
- Display attendance information

### File Management

- Save student records to text files
- Read previously saved student records

The project demonstrates:

- Constructors

- Interfaces
- Inheritance
- Method overriding
- Method overloading
- Static methods
- `super` keyword
- Runtime polymorphism
- ArrayList
- Multithreading
