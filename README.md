# Student Academic Management System

## 1. Project Overview

The **Student Academic Management System** is a command-line Java application designed to manage basic academic information of students.

The system allows users to add and manage student details, course marks, attendance records, academic performance reports, and saved student records.

The project demonstrates important Java programming concepts including classes, constructors, inheritance, abstract classes, interfaces, method overloading, method overriding, runtime polymorphism, exception handling, loops, Java I/O, and multithreading.

---

## 2. Objectives

The main objectives of this project are:

- To manage student information through a menu-driven system.
- To maintain course names and marks.
- To calculate total and average marks.
- To determine the overall grade of a student.
- To maintain student attendance information.
- To calculate attendance percentage and attendance status.
- To generate academic performance reports.
- To save student records into text files.
- To read previously saved student records.
- To demonstrate important Java and Object-Oriented Programming concepts.
- To provide a simple command-line based academic management system.

---

## 3. Features

The application provides the following features:

1. Add a new student.
2. Display all students.
3. Search for a student using Student ID.
4. Update student information.
5. Delete a student.
6. Add course marks.
7. Add attendance information.
8. Generate an academic performance report.

## 4. Major Functional Modules

### 4.1 Student Management

This module manages basic student information such as:

- Student ID
- Student Name
- Department

The module supports:

- Adding students
- Displaying students
- Searching students
- Updating student information
- Deleting students

### 4.2 Academic Management

This module manages course information and marks.

It provides:

- Course name storage
- Marks storage
- Total marks calculation
- Average marks calculation
- Grade calculation

### 4.3 Attendance Management

This module stores:

- Total classes
- Attended classes

It calculates:

- Attendance percentage
- Attendance status

The system considers attendance of 75% or above as satisfactory.

### 4.4 Report Management

The report module generates an academic performance report containing:

- Student information
- Course performance
- Total marks
- Average marks
- Overall grade
- Attendance details

### 4.5 File Management

Student records can be saved as text files inside the `data` directory.

The system can also read previously saved records using the Student ID.

## 9. How to Run

**Step 1: Open the Project**

Open the `StudentAcademicManagementSystem` folder in Visual Studio Code.

**Step 2: Open the Terminal**

Open the integrated terminal in VS Code.

**Step 3: Compile the Source Files**

```bash
javac -d out src/*.java
```

**Step 4: Run the Application**

```bash
java -cp out Main
```

The menu-driven application will start in the terminal.

## 11. Input Validation and Error Handling

The application validates different types of user input.

- Invalid menu input
- Invalid Student ID
- Empty student name
- Empty department
- Empty course name
- Marks outside the range of 0 to 100
- Invalid attendance values
- Zero total classes
- Negative factorial input
- Missing saved student record
- File input/output errors

Java try-catch blocks are used to handle input and file-related exceptions without abruptly terminating the application.

## 12. Academic Grade Calculation

The system calculates the grade using the student's average marks.

| Average Marks | Grade |
|---------------|-------|
| 90 and above  | A+    |
| 80 - 89.99    | A     |
| 70 - 79.99    | B     |
| 60 - 69.99    | C     |
| 50 - 59.99    | D     |
| Below 50      | F     |

---

## 13. Attendance Calculation

Attendance percentage is calculated using:

```text
Attendance Percentage = (Attended Classes / Total Classes) × 100
```

If the attendance percentage is 75% or above, the status is displayed as:

> **Satisfactory**

Otherwise, the status is:

> **Low Attendance**

---

## 14. File Storage

When a student record is saved, the application creates a text file using the Student ID.

For example:

```text
data/student_101.txt
```

The saved record contains:

- Student ID
- Student name
- Department
- Course details
- Total marks
- Average marks
- Overall grade
- Attendance information

The saved record can later be displayed through the **Read Saved Student Record** option.

## 16. Limitations

The current version has the following limitations:

- Active student information is stored in memory while the application is running.
- Saved records are stored as text files rather than a database.
- The application does not currently provide a graphical user interface.
- The system does not include user authentication.
- Attendance is maintained as a single record for each student.
